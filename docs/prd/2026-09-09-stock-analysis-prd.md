## 1. 背景与目标

### 1.1 背景

个人投资者与小型投资机构在分析个股时，往往面临信息分散、分析框架不统一、专业研报门槛高等问题。用户需要一种能够将华尔街分析师的研究框架（商业模式、财务健康、护城河、估值、风险、增长潜力、机构视角、多空辩论）标准化输出、并以通俗易懂语言呈现的工具。

### 1.2 目标

为股票投资者提供一个输入股票代码即可生成「华尔街式完整股票分析报告」的 Web 功能，报告结构专业、解释通俗、数据可追溯，帮助用户快速建立对标的公司的系统性认知。

### 1.3 成功指标

- 报告生成成功率 ≥ 95%（有效股票代码）。
- 单份报告生成耗时 ≤ 30 秒（不含外部数据获取）。
- 用户报告满意度评分 ≥ 4.2 / 5（基于结构化反馈）。
- 报告核心 8 个章节完整率 = 100%。

---

## 2. 目标用户

### 2.1 主要用户

- **个人投资者**：希望通过系统化分析辅助长期投资决策，但缺乏专业研报资源。
- **金融从业者/分析师**：需要快速生成分析框架草稿，作为深度研究的起点。
- **投资教育用户**：希望学习如何像专业机构一样分析公司。

### 2.2 用户痛点

- 财务报表、行业数据、竞争对手信息分散在多个平台。
- 缺乏统一、可复用的分析框架。
- 专业研报术语晦涩，普通投资者难以理解。
- 难以快速获得多空双方观点的平衡视角。

## 3. 用户故事

- 作为个人投资者，我希望输入一只股票代码后获得完整的分析报告，以便快速判断该公司是否值得深入研究。
- 作为金融分析师，我希望报告包含财务趋势、护城河评分和估值对比，以便节省初步研究时间。
- 作为投资教育用户，我希望分析解释通俗易懂但框架专业，以便学习投资分析方法。
- 作为长期投资者，我希望看到 bull/bear 辩论和 12-24 个月展望，以便理解不同市场情景下的潜在收益与风险。

## 4. 功能清单

### 4.1 股票代码输入与校验

- **功能描述**：用户输入股票代码（如 AAPL、00700.HK、600519.SH），系统进行格式校验与合法性校验。
- **优先级**：P0
- **验收标准**：
  - [ ] 支持美股、港股、A 股常见代码格式。
  - [ ] 对无效代码给出明确错误提示。
  - [ ] 支持历史输入快速选择。

### 4.2 华尔街式分析报告生成

- **功能描述**：基于股票代码生成包含 8 大章节的结构化分析报告：商业模式、财务分析、竞争优势、估值分析、风险分析、增长潜力、机构视角、多空辩论。
- **优先级**：P0
- **验收标准**：
  - [ ] 报告必须包含全部 8 个章节，缺一不可。
  - [ ] 每个章节包含数据、结论与通俗解释。
  - [ ] 护城河评分以 1-10 分展示并附理由。
  - [ ] 风险按危险程度从高到低排序。

### 4.3 报告可视化展示

- **功能描述**：以网页形式展示报告，支持章节导航、关键指标高亮、图表辅助（趋势图、对比图）。
- **优先级**：P0
- **验收标准**：
  - [ ] 页面支持章节锚点导航。
  - [ ] 关键财务指标以卡片或表格形式突出展示。
  - [ ] 移动端与桌面端均可正常阅读。

### 4.4 报告导出与分享

- **功能描述**：用户可将报告导出为 PDF 或 Markdown，或生成分享链接。
- **优先级**：P1
- **验收标准**：
  - [ ] 支持导出 PDF，格式与网页展示一致。
  - [ ] 支持导出 Markdown 源文件。
  - [ ] 分享链接可访问且不过期（默认 30 天）。

### 4.5 分析历史管理

- **功能描述**：保存用户近期分析记录，支持查看、重新生成、删除。
- **优先级**：P1
- **验收标准**：
  - [ ] 记录最近 30 天的分析报告。
  - [ ] 支持按股票代码搜索历史。
  - [ ] 用户可删除单条历史记录。

## 5. 非功能需求

- **性能**：单份报告端到端生成时间 ≤ 30 秒；页面首屏加载时间 ≤ 2 秒。
- **安全**：禁止在前端暴露外部金融数据 API Key；用户输入需做校验与转义；报告内容需标注数据来源与免责声明。
- **兼容性**：支持 Chrome 120+、Firefox 120+、Safari 17+、Mobile Safari / Chrome。
- **可用性**：系统部分外部数据源不可用时，能够降级使用缓存数据或给出明确提示，不影响整体页面可用性。
- **合规性**：报告头部与底部必须包含「仅供参考，不构成投资建议」免责声明。

---

## 6. 边界与约束

- 本功能仅生成分析性报告，不提供实时交易、下单或投资建议。
- 不承诺数据实时性，财务数据以最新可获取的财报/公开数据为准。
- 不覆盖加密货币、基金、债券等非股票资产。
- 外部数据源优先使用免费/低成本 API，若成本过高则后续迭代再评估付费方案。
- 不在报告中泄露内部算法提示词或数据供应商身份。

---

## 7. 风险与依赖

| 风险 | 影响 | 缓解措施 |
| :--- | :--- | :--- |
| 外部金融数据 API 不稳定或限流 | 高 | 引入缓存机制与多家数据源备选方案 |
| AI 生成内容出现事实性错误 | 高 | 在关键数据点标注来源，提供人工复核入口，关键财务数据优先使用结构化数据 |
| 合规监管对投资建议表述敏感 | 中 | 每份报告强制展示免责声明，避免给出明确买入/卖出建议 |
| 长报告渲染性能差 | 中 | 采用流式输出/分章节懒加载，优化大文档渲染 |
| 多市场代码格式差异大 | 低 | 统一代码解析规则，提供输入示例与自动补全 |
